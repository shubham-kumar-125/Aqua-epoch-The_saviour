# Team details for the Round 1 PDF

Edit `team_details.json` with the confirmed team name, member names, and contact information, then run `python run.py report` to refresh the PDF and companion Markdown report.

The report generator prints blank or bracketed placeholder values as **Not provided**. It does not infer participant identity or invent contact information. The SPOC defaults to `Prakshaale`.

The training date and model version are read from the saved training metadata; regenerating the report does not retrain the models.
